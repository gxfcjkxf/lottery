# 当前投注容量基线

本组验证源代码提交`e129a6f03a03240309a27c9f1f5e1ece93979da3`在受控本机环境中的500用户、500请求每秒投注负载。压测通过真实TCP HTTP接口和PostgreSQL事务创建注单及扣款，通知消费者同时运行；会话预先准备，不包含登录、TLS、反向代理或生产日志开销。

## 环境与结果

2026年10月9日在darwin/arm64、10逻辑CPU、Go1.27.1、PostgreSQL17.5运行。独立数据库实例仅监听回环55436；使用当前单份SQL基线，每轮使用独立测试schema，不修改55432开发库或体验数据。应用连接池上限20，每名合成会员预充值100,000积分，每笔投注1积分。

| 场景 | 持续时间 | 成功新单 | 计划至回执P95 | 计划至回执P99 |
| --- | --- | --- | --- | --- |
| 单品牌 | 30秒 | 15,000 | 42.26毫秒 | 71.10毫秒 |
| 双品牌 | 30秒 | 15,000 | 7.46毫秒 | 8.81毫秒 |

单品牌及双品牌30秒报告分别见[单品牌原始报告](performance/current-baseline-500-20261009.json)和[双品牌原始报告](performance/current-two-brand-500-20261009.json)。两轮计划、启动、完成和成功均为15,000，全部201回执；零丢弃、未知提交、窗口外注单、余额差额、数据库死锁及通知消费者错误。每轮15,000笔新注单对应15,000笔借记，期末余额49,985,000积分。按含服务端排空的墙钟时间计算，新单吞吐分别为499.89和499.90笔/秒，不将其四舍五入为严格500笔完成/秒。

[双品牌5分钟原始报告](performance/current-two-brand-500-five-minutes-20261009.json)的150,000个计划请求全部启动、完成且返回201；150,000笔新注单、借记及已确认回执一致，期末余额49,850,000积分。错误、丢弃、未知提交、超截止、账户差额、死锁、通知消费者错误均为0。150,000条站内通知投递记录已标记sent，期末待投递为0；这不证明用户已阅读或外部渠道送达。含服务端排空的新单吞吐499.94笔/秒，实际峰值在途86个请求。500个合成会话不是500台真实终端，也不是500笔始终同时在途。独立实例运行结束后已停止，缓存目录保留供检查。

## 复跑与核验

先准备独立回环PostgreSQL实例，不能使用55432原开发实例。以下命令在`backend`目录运行；报告路径必须不存在，测试不会覆盖旧报告。调整品牌数为1可复跑单品牌；300秒为长轮示例，不代表项目方已批准生产峰值持续时间。

```sh
TEST_DATABASE_URL='postgres://lottery_test@127.0.0.1:55436/postgres?sslmode=disable' \
LOTTERY_CAPACITY_CONFIRM_ISOLATED=yes \
LOTTERY_CAPACITY_REPORT='/absolute/fresh-report.json' \
LOTTERY_CAPACITY_USERS=500 LOTTERY_CAPACITY_BRANDS=2 \
LOTTERY_CAPACITY_RATE=500 LOTTERY_CAPACITY_SECONDS=300 \
LOTTERY_CAPACITY_INFLIGHT=500 LOTTERY_CAPACITY_POOL=20 \
go test -tags capacity ./internal/httpapi -run '^TestBettingCapacity$' -count=1 -v -timeout 8m
```

在仓库根目录运行`pnpm test:capacity-report /absolute/fresh-report.json`检查成功受控基线。核验要求计划请求全部启动、完成且返回201，注单、借记、扣款及已确认回执一一匹配，余额正确，无错误、丢弃、未知提交、死锁或通知消费者错误；不允许报告声称生产或主从容量通过。重复键及截止拒绝场景的预期不同，不使用这个成功基线核验器。

## 剩余验收

这些结果只证明对应受控场景。尚需验证复杂玩法与复式规模、完整佣金/结算/提现组合负载、从库与复制故障、生产TLS及代理、真实验证服务与终端、客户生产参数和恢复演练。P95/P99验收阈值及正式峰值持续时间由项目方确认，核验器不自行设定。报告保留`production_capacity_accepted=false`，不能据此关闭完整性能或高可用验收。
