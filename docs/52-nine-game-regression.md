## 两级价格和购买快照

Computer Use逐个发布九个彩种的两级测试价格：加拿大普通“大”或百家乐“庄”，平台2.3、品牌2.2；牛牛闲A，平台1.04、品牌1.03；六合彩特码01和49，平台50、品牌49。平台更新后、品牌尚未确认新版本时，用户端销售暂停；品牌发布后用户端读取品牌价格。

逐个在用户端选择、预览，核对选项、注数、积分及价格。六合彩二全中选01、02、03展开三注，再加一注特码49，预览共四注40积分。浏览器停在预览环节；最终合成积分购买通过本地HTTP请求执行，由运行中的worker结算。

九笔购买均使用相同幂等键重复提交，返回同一注单。购买完成后，通过两个后台恢复原示例价格，再发布开奖结果，验证结算仍读取购买快照。加拿大两级恢复普通2、牛牛1；六合彩01和49恢复48.99，其余原配置不变。
