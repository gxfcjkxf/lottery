# 零原派发后的佣金保护

原派发为0且没有原派发流水，不代表该周期没有实际资金。运营人员可能已经人工增加佣金；开奖结果更正后，必须按真实已入账净额计算差额，不能再全额派发。

例如原核算及派发为0，人工修正到1，新核算为1时差额为0。原支付保留并标记需要更正，新差额按保存模式取得批准；零差额完成不生成资金流水，最终实际净额仍为1。

新核算为0时，应取得新批准后追回1，只使用佣金可用积分。余额不足按既有整周期暂停和显式继续规则处理，不扣其他来源、不自动解冻。

原人工修正、账本和审计不可改写。资金检测包含原派发、人工修正和已执行更正；只读分析不授权派发。

这些规则包含在当前完整基线和正常业务服务中。项目未发布，不再提供旧版本stale状态恢复、离线升级检查点或历史恢复申请审核入口。
