# UI 与交互规格

“批量对账”新增独立品牌业务引用区，明确加载后显示41表覆盖、完整计数和最多100项问题；源/引用数量不是资金笔数，摘要不是修复令牌。原持久任务的范围、确认和未知写入恢复不变，PC/360px双语与迟到响应隔离见[37号合同](37-brand-business-inventory.md)。

佣金周期详情在明确选择run后追加独立历史收益与未舍入分配区，分别分页，分配可按代理/注单筛选。中英文区分整周期精确合计、舍入积分与实际入账；范围变化丢弃旧响应/迟到401，不触发财务写入，见[35号交接](35-commission-allocation-history.md)。

审计页已接入明确品牌和UTC时间筛选、逐页查询、脱敏前后详情及独立权限的完整CSV导出；PC/360px及双语布局、摘要验证和迟到响应隔离规则见[32号审计交接](32-audit-query-and-export.md)。下载只在已提交审计和客户端内容验证后触发，不移动积分。

## 1. 终端策略

- `user-web`：用户端独立 PWA，移动端优先，同时适配桌面浏览器。
- `admin-web`：品牌后台独立项目，按品牌配置的管理员、运营、财务和客服角色提供操作，适配PC和移动端。
- `platform-web`：独立总后台项目，使用平台账号登录，查看跨品牌数据并创建品牌；会员信息只读，不参与品牌玩法审核或财务操作。
- 第一阶段不上架任何应用市场。
- 三个项目可共享基础类型和国际化工具，但品牌后台与总后台不能共用菜单、登录会话或部署产物。
- 未登录或会话未校验时，后台只显示登录入口，不渲染菜单、品牌切换器、工作台、演示数据或私有业务内容。账号类型错误时停留在登录页并说明正确入口。

### 1.1 当前 PWA 实现

三端独立 manifest、PNG 安装图标及生产 worker 已接入，仅缓存公开哈希静态资源。HTML、私有 API 与写请求不缓存，不提供离线业务页面、提交队列或自动重放。安装元数据使用项目通用名称/图标，不随当前品牌动态变更。生产构建1440px/360px缓存验证见[44号交接](44-pwa-production-cache.md)；真机安装和资金断网恢复另行验收。

## 2. 品牌主题

主题配置至少包含：

- Logo、favicon；
- 主色、辅助色、成功/警告/错误色；
- 字体和字号层级；
- 圆角、阴影、按钮样式；
- 登录页、首页、游戏卡片和公告样式；
- 默认语言、可用语言和文案覆盖。

继承顺序为平台默认 → 品牌覆盖。主题配置发布后清理缓存并返回新版本号。

### 已实现的品牌展示配置

管理端已接入完整替换配置、核对提交、原键重试和分页历史查询。用户端从公开品牌上下文读取生效配置；管理端只使用当前登录账号所选品牌的已发布配置，不将编辑草稿应用到整个后台。发布后重新读取才代表最新状态；其他已打开的页面在重新加载品牌上下文时生效，不提供实时推送。

配置包含展示名称、标志文字、Logo 与 favicon 地址、五种颜色、字体/字号/圆角/阴影预设、默认及可用语言，以及中英文标语和公告。每个字段必须提交；显式 `null` 表示继承平台默认，文案的空字符串表示清空。平台默认当前为程序固定值，不提供平台默认值编辑页面。

支持的语言代码为 `en`、`zh-CN`，可用语言不得为空，必须包含生效的默认语言。字体为 `system`/`serif`/`mono`，字号为 `compact`/`standard`/`large`，圆角为 `square`/`soft`/`round`，阴影为 `none`/`subtle`/`lifted`；这些是受限预设，不是任意 CSS。积分、编号等专用等宽文本和部分固定尺寸控件保留原样。

### 管理端语言切换

管理端提供 English 和简体中文选择，采用明确的 Vue 文案绑定，不遍历或替换页面 DOM。应用外壳、登录、成员与权限、品牌配置、资金与提现、佣金页面，以及彩种/规则与嵌套编辑器、期次/开奖、注单/取消/结算/更正、代理/加入码、报表、通知和合规面板均接入双语。静态文案检查自动枚举全部 Vue 组件，新增页面不能通过遗漏白名单逃过检查；这项源码检查不代替真实交互、财务流程或客户终端验收。

登录前和没有当前品牌已发布展示配置时采用平台管理默认中文，并提供两种语言。能够读取当前所选品牌的已发布配置时，默认及可用语言跟随该配置；不从用户端入口品牌借用语言。显式选择的语言优先，但仅在当前品牌允许时使用，否则回退到品牌默认；返回允许该偏好的品牌时恢复偏好。草稿配置不会改变控制台语言。

浏览器仅在 `lottery.admin.locale` 中保存 `en` 或 `zh-CN`，不保存账号、密码、请求正文或未知写入。存储被禁用时仍可切换，完整刷新则不能保证保留偏好。语言切换不发业务写请求，不重新提交或清除冻结意图。应用提示以双语消息或受限本地映射显示；服务端原始错误、品牌和成员名称、备注、原因、审计 JSON、编号、权限键及积分整数保持原值，不作自动翻译。中文和英文运营文案字段也不随界面切换改写。页面根 `lang` 同步更新，可访问名称与显示文案使用相同语言。

规则模型、运算符、目标、属性和状态选项只翻译标签，必须保留明确且语言无关的 `value`。切换语言不重建选号、奖级、验证用例或配置 AST，不改变倍率、赔率、积分字符串及提交字段；客户自定义玩法名称、属性名称和规则数据仍为原值。投注、账本、提现及佣金报表翻译列名/解释，但完整 CSV 字段及机器协议不随界面语言变化。

加入码查询开始立即撤销旧的核对勾选；查询尚未结束时，冻结请求核对框、确认与原键重试不可操作，提交函数也检查读取状态。查询完成后必须再次核对原请求；切换语言本身不撤销勾选、不改变冻结 JSON 或幂等键。取得匹配回执后先确认原写入，再独立刷新当前目录；刷新失败不能把已确认写入重新变成未知。

资金页的充值、中奖、佣金、赠送及可用、人工冻结、系统冻结、提现预留标签随语言变化，实际来源/状态键和整数金额不变。提现规则页只编辑政策，不生成申请或冻结出款；资格预览和申请由独立提现模块按投注时N快照重新计算，N必须大于0，修改只影响新投注。对账结果未知时，切语言及只读刷新仍须保留原正文和原幂等键；中文原因和操作记录原样显示。窄屏为底部导航留出滚动空间，固定导航按可见视口限宽；对账状态徽标不能被压缩成文字溢出，短标签与长说明可分行。浏览器检查可见视口和文档内容宽度，不仅比较可能已被溢出撑大的innerWidth。

公告和标语按纯文本显示，不能执行 HTML。素材仅保存地址，不提供上传或服务器下载：允许受限 HTTPS DNS 形式主机地址或 `/icons/`、`/brand-assets/` 相对地址，扩展名限定 png/jpg/jpeg/webp/ico，拒绝 SVG、IP、端口、查询参数、片段、凭据和路径穿越等。主机名检查不等于 DNS 解析或素材内容安全验证；素材托管、实际 MIME 检查仍由部署方负责。浏览器匿名且不发送引用页加载，Logo 失败回退到文字；动态 favicon 不更新已经安装的 PWA manifest 图标。

展示配置与认证设置、品牌运行状态共用品牌版本。版本冲突必须重新读取后人工核对，不能自动覆盖。停用品牌只读；品牌暂停不禁止修改展示配置。此功能不改变品牌域名、基础名称、时区、用户资料、权限、订单或积分；域名绑定及品牌创建由独立管理模块处理。

### 新建品牌

已登录“品牌和域名”页面按精确平台权限显示创建表单。无需先选择已有品牌；填写代码、名称、默认语言、时区和原因，核对后提交。创建固定暂停/版本1，不自动授权或创建业务数据。成功回执与真实列表刷新分开处理，不自动选择新品牌；平台入口没有公开用户品牌时显示相应提示，不冒充后台认证失败。

请求发出前立即冻结正文和幂等键。断网、5xx或畸形/不匹配的201回执保持未知意图，离开页面后返回仍只允许原请求重试；冲突须明确放弃后重新填写。缓存仅存当前页面应用的账号隔离内存，完整浏览器刷新/关闭不保留，不写localStorage/IndexedDB。会话退出或换账号清除代次，旧回调不得清除新请求或更新新账号。若完整刷新丢失未知键，先人工核对创建记录与审计，不能直接重复创建。

客户端限制与服务一致，并额外拒绝名称/原因的Unicode行分隔符；时区表单只接受UTC或含斜线的浏览器支持时区。名称和原因按UTF-8字节计数，不将字符数当作字节上限。PC及360px浏览器执行真实提交后丢失响应/原键重放验证；不代表苹果、安卓或鸿蒙真机已验收。

### 品牌域名管理

品牌页面提供绑定列表、新增、编辑启停/主域名、核对提交和分页历史。新增表单默认禁用；已有绑定不能改名、转品牌或删除。主域名必须启用，选择新主域名会在同一事务将旧主域名降为普通绑定，不重定向访问，也不禁用旧域名；可不指定主域名。禁用当前管理入口可能使该入口后续请求被拒绝，操作前须准备其他可用管理入口。

前端和后端限制新主机名为小写ASCII多标签DNS形式、总长不超过253字节、各标签不超过63字节；拒绝IP、URL、端口、通配符、末尾点、纯数字/十六进制末标签及localhost/local/localdomain/internal后缀。这些限制不证明域名归属、DNS可解析或TLS已配置，部署方须另行配置并验证。原本保留的localhost/IP绑定可管理状态，不作为新增规则的例外入口。

读、历史和提交使用独立请求代次；未获确认的写入保留原方法、路径、正文及幂等键，刷新或离开返回不能另建请求。冲突后重新读取并明确放弃，成功回执后独立读取最新列表。域名管理采用与展示配置相同的账号/品牌隔离和停用只读规则，主机名变更不改变会话所属品牌、用户、积分或订单。

### 风控与合规管理页

管理端独立导航及手机“更多”入口提供品牌合规政策、核对后完整替换、分页历史、显式伪检查和真实业务闸门拒绝记录。页面醒目标明：服务端已检查新注册/首次入品牌及投注预览/提交，开启却未接适配器时拒绝新业务；提现积分流程已接入，但真实支付及身份验证未接入，不能据此上线，不得录入证件或生日。关闭不代表已验证，review不冒充真实审核队列。显式管理员模拟与真实业务拒绝分栏展示，记录查询不触发新的审核或资金操作。

权限来自目标品牌权限映射及独立平台权限，不把扁平并集或超级管理员身份当授权。政策与检查均需确认才发送；请求发出前冻结意图，未知响应切页面仍用原正文/键重试，冲突重新读取后必须显式放弃旧意图，不自动套用草稿。成功写入与后续读取失败分开展示，会话/品牌切换隔离迟到回调。意图只在当前应用内存，完整浏览器刷新或关闭不能恢复，需人工核对审计再继续。

最低年龄18–120是表单工程范围，默认null；国家代码按两个大写字母校验，不证明国家存在、准入或法律允许。配置版本独立，不能使用品牌共享版本提交。只读账号可查看已发布政策、历史和决策，不能改配置或运行检查。

### 人工充值记录

`/recharge` 使用真实已登录会员资料查询本品牌记录，替换演示金额、付款凭证表单和仅显示“已提交”的假按钮。未登录提供登录入口；登录后显示待处理、已确认和已取消记录，支持全部/单状态筛选、每页20条、详情及刷新。记录金额、版本和总数保留精确整数字符串；中英切换只改变标签和单位，不改状态键或数据。创建、确认及查询时间明确显示UTC。

说明明确充值由后台单人创建/确认/取消，本页不发起或接收付款，不提供用户提交充值、凭证上传、地址或支付按钮。确认记录只表示历史内部积分入账，当前余额应看钱包；列表是当前订单状态，不是不可变历史或付款回执。详情只显示记录编号、金额、状态、版本、时间及确认后的账本条目编号，不显示后台证明、备注、操作人或理由。

查询失败不得用模拟记录或缓存余额代替。读取按会员、品牌和请求代次隔离，刷新/筛选关闭旧详情；换会员/品牌、卸载或会话失效清除旧记录并忽略迟到响应。其他标签页改变登录Cookie时，新响应与原会员不匹配即清空并要求重新登录；迟到的资料读取不能重新挂载旧会员。正常只读操作仅发送GET，不增加充值单、积分或流水。手机长编号可换行，详情按钮和筛选控件可触达，页面不得水平溢出。

### 3.2 选号页

选号页必须始终显示：

- 当前品牌和彩种；
- 当前期次、投注截止倒计时和期次状态；
- 玩法名称、规则摘要和规则版本；
- 普通号码、特别号码或数字位的选中状态；
- 号码属性标签；
- 排除号码入口；
- 复式展开注数；
- 倍投输入和合法范围；
- 单注积分、总积分、可用积分；
- 清空、随机选号、下一步和提交按钮。

确认页不得重新改变选号；如果期次、规则或余额在提交时发生变化，必须重新确认并展示原因。

### 3.3 状态和错误

统一处理：加载中、无数据、网络断开、品牌暂停、期次截止、余额不足、限额超出、重复提交、权限不足和服务暂不可用。

上期未完成结算或取消退款时，同彩种下一期不得显示为可投注；预生成的下一期仍为待开始。页面显示当前期次状态并禁用确认/提交入口，不能仅凭计划开始时间将按钮放开。窗口过期后的跳过保持原时间；必须以服务端实际开放状态重新获取预览，不沿用上一期确认快照。服务端仍执行最终门禁，客户端禁用不是资金安全边界。

## S5-a4 整期取消与退款接入边界

- “期次和开奖”增加独立期次取消面板。可直接输入期次 UUID 并读取该期真实详情与版本，不依赖列表默认期次；期次版本与取消任务版本明确分开。只读权、发起取消权、失败重试权各自独立，超级管理员不能写入；仅写权限时不调用 GET。
- 投注取消/判定取消、结构化原因与操作说明经核对后再确认。期次立即停止，但必须显示任务处理中/失败/已完成以及总数、待处理、已退款、原已退款和失败计数；不能以 202 起始响应宣称全额退款已完成。已完成快照与历史原始数据只读。
- 网络不确定时固定正文与幂等键，按账号/品牌隔离保存于 sessionStorage，刷新仍可原请求重试；不保存登录凭据。改变账号、品牌、期次或卸载后，旧响应不能覆写当前视图。确定 409 解除旧意图并要求重新核对，不拿任务版本替代期次版本。
- 有读取权时最多每 10 秒读取摘要、连续 6 次，随后可手动刷新。失败任务显示结构化错误码，运营核对并填写原因后显式重试；不自动恢复失败任务。该界面不执行已结算回溯或支付。

## S5-a5 单注判定取消接入边界

- 注单详情新增独立的“判定取消”权限与入口，普通取消、异常标记、判定取消不互相隐含。核对 no_result/invalid_result、非空且最多 500 UTF-8 字节原因，再确认只取消本单并全额原来源退款；确认后锁定原因类型、正文和请求编号。
- 未知网络结果保留原 body/键，重试或按匹配的单注证据核实；确定 409 后重读并重新核对版本、状态与判定依据。判定证据只读显示操作者、结果版本、原因、当时结果引用和退款引用，原异常记录继续保留；整期取消没有单注人工记录时给出明确说明。
- 规则版本编辑器按需加载，避免其完整编辑/验证功能扩大管理首页主包；权限和服务端验证不因懒加载改变。视口回归仍不等同于三类手机 OS 真机验收。

## S5-b 用户公开开奖与历史期次

- `/results` 不再显示固定示例号码。全品牌真实彩种目录、精确期号筛选、开奖/历史切换、上一页/下一页、刷新与当前结果详情使用只读接口；历史需要选彩种。空目录、无匹配结果、尚无结果、错误重试及暂停分别显示，不生成假的开奖或中奖金额。
- 彩种详情增加该彩种最近采用结果和跳转历史入口。三组号码原样显示，按数字位置标出零和重复号码；普通/特别号码不排序去重，以兼容允许重复或有顺序的 X+Y 模型。时间按彩种时区显示计划/实际开奖时间。
- 取消期次保留历史号码但明确标红说明“仅作记录，不用于有效判定或派奖”；已开奖、结算中、已结算与取消状态不能混淆，展示号码不代表订单获奖或已到账。
- 结果详情重新 GET 当前结果并显示公开记录编号；替换后的旧结果 404，不回退到旧快照。品牌/彩种/期号/页签改变或卸载后旧响应不得覆盖新上下文；失败和改筛选清除旧号码及详情。无效 URL/组件彩种参数不得退化成查询全部彩种。
- 完整双语、360px 与 PC 布局；UUID、长中文期号可断行。读取失败只提供安全重试，无投注/资金动作，不自动无限轮询。视口回归不代替真实手机 OS、PWA 安装或容量验收。

## S5-c1 后台核算预览

注单详情嵌入独立核算区域，明确“不派奖、不改变注单或期次状态，不代表已结算”。实际订单/期次版本、当前开奖结果及旧规则 hash 来自只读上下文；原因→核对→明确确认仅创建预览记录。既有异常/取消的单只显示排除，不运行正常中奖计算。

结果区展示命中/未命中、精确有理数中间金额与整数结果、错误码、hash、操作者/审计，以及实时派生的当前/过时标记；不得用“已到账”表示此数据。历史与复式明细每页 20，trace 按需展开；手机长 ID/trace 在容器内换行或滚动。只读账号/超管没有创建控件。

未知回执保留原 body、账户/品牌/注单范围和键，仅可原样重试；只读核对历史不能证明原请求成功。已确认有效回执后 GET 失败不恢复未知状态，明确显示已保存但读取失败并清旧明细。独立请求世代保护多读取通道，防止迟到的另一页/记录覆盖；切账号/品牌/注单和卸载取消可见数据。

有效回执后的任一 GET 401 同样上报会话失效并清除登录状态/明细；已提交记录继续保留，不回退为未知写入，也不重新发送创建请求。

## S6-b 用户真实站内信

- `/notifications` 不显示固定演示消息/假未读数；实际Cookie解析当前会员，新消息按不可变双语模板快照显示，旧v1继续固定旧文案，积分保持精确整数。
- 支持加载/空页/读取错误/未登录、分页、单条已读和“本页标为已读”；角标仅使用已成功读取的未读总数，退出、卸载或失效时移除。
- 未知写入保留精确 IDs、账户范围与原幂等键；只读重载后即使消息已经读过仍保留未知提示和同请求重试入口。明确失败才解除旧意图。加载/写入时禁用冲突操作；品牌切换与卸载后旧响应不得覆盖新范围。
- 中英文正文用快照插值，保留换行；不接受富文本/HTML/外部地址、未知或私密变量。派奖/冲正另有不可编辑的系统事实说明，不等于当前余额或最终中奖。
- 开奖通知已面向本期投注会员去重，含取消/异常注单；更正追加历史消息，不覆盖旧结果，见[31号合同](31-draw-result-notifications.md)。外部渠道仍未实现，不以站内sent推断邮件/短信/Telegram已发送。提现六种历史状态已接入站内通知，不将内部paid解释成真实外部转账。

S7-l 后台“通知模板”接入八类事件、两种语言的当前配置、独立修订历史和审计。固定样例预览不发送通知，修改需原因、核对及单人确认。发送中和结果未知分开显示，冻结正文/键按账号、品牌、事件保存在页内内存，离开返回或列表未加载仍能显式同键重试；只读刷新不确认未知写入，退出/换账号清理。平台明确查看权限无需品牌伪成员，超管不能写。PC双栏、手机单栏，长UUID、文本和提示换行；界面不再标为原型。契约见 [模板说明](12-notification-templates.md)。

## S6-a 后台提现规则配置

- “资金与账本”提供按需加载的品牌/彩种真实配置，政策编辑与提现订单处理分开。enabled保存不代表正式资格已接入；未配置资格器时用户申请入口明确禁用，不显示虚构达标比例。
- 品牌范围、来源、审核模式、N；彩种只覆盖 N 或留空继承，区分 "0" 与 null。有效 N/来源/双方版本读取服务端已保存记录，未保存草稿不影响显示；品牌保存后重读彩种有效值。
- 两步核对、必填原因、冻结正文与原键；未知网络/5xx 原请求重试，读取同值不能证明本次成功；确定冲突重读后新确认。回执必须匹配范围、下一版本、配置与审计。品牌/账号/彩种改变或卸载后迟到响应不得覆盖新范围；未知意图仅在当前页面会话内存隔离保留，不跨刷新/关闭持久化。
- 历史只读、分页，人员/原因/原版本可查。规则读写与目录读权限分离，超管无保存，可直接 UUID 查彩种。金额和 N 用字符串/整数逻辑，360px/PC 可断行；不以界面测试证明提现完成或真机兼容。

### 已接入提现订单页面

用户提现页读取真实入口状态、本人订单/历史及只读流水快照，显示基数、实际有效金额/单数、未舍入的信用额度分子/分母和达标条件。新提交要求入口可用且最新读取的流水条件达标，未配置/未读取/失败时禁用；旧快照不是授权，POST会重新检查。金额分配明确使用三种来源正整数，账号确认上下文来自真实入口。未知写意图保留原正文/键及上下文，读取新快照不确认原请求；最新快照不达标也不能阻止已提交请求的原键确认。写入确认或确定的不合格拒绝后清除旧快照，切账号/品牌及过期会话清除旧显示，迟到回调不能覆盖新身份；外国身份响应不展示并触发账号刷新。中英文字、精确长整数在PC/360px布局可换行，不显示假余额或达标比例。状态为审核中、提现中、已提现、已驳回、失败、已取消；第一期不执行外部付款。

运营页支持所选品牌的真实订单分页、会员/状态筛选、详情及历史，按明确动作权限提供批准、驳回、取消、失败和内部标记已提现。每次写入先核对版本与原因；标记已提现明确说明不执行外部支付。超级管理员只查询，不能审核或改金额。中文/英文切换不改订单键、积分、原始原因或未知请求。

客户端拒绝不完整、跨范围或状态/版本不一致的回执。响应丢失及畸形写入结果保留原正文、幂等键与确认上下文，只允许显式重放；只读刷新、筛选和历史查询不能清除未知意图。账号、品牌或权限范围变化清除私有视图并隔离迟到响应。冻结意图只在当前应用内存中保存，完整刷新/关闭后须先核对记录，不直接重复申请。

## S5-c2 结算配置与任务

“期次和开奖”提供品牌真实配置和期次 UUID 查询。模式初始未配置；保存配置、启动任务、批准和重试均须原因、两步核对、明确确认，不由 UI 自动启用。区分当前政策与任务历史快照，核算金额与已入账金额分开。所有目标分页显示注单/会员、核算/账本 ID、状态及错误码；异常排除不是失败重试。

未知写入冻结原正文、幂等键和账号/品牌/期次/操作范围；只读刷新可观察任务进度但不能解除未知提示。同请求取得匹配回执才确认成功，随后主库 GET 读取最新状态。有效回执后 GET 失败显示“已确认但读取失败”，不重新冻结/重放；401 清除账号及旧品牌数据，迟到响应不得恢复。意图只在当前页面会话内存保留，不跨硬刷新承诺恢复。政策查看与结算查看分别授权；超管只读。

核算不入账时禁止宣称已中奖积分到账；只有实际注单 settled_at 才显示已应用中奖积分与不可改写账本引用。PC/360px 页面以长 UUID 换行、分页和单列布局适配，不据此宣称真机 PWA 验收。

## S5-c3 开奖更正

“期次和开奖”提供直接 UUID 查询，旧结果/模型/版本/当前 job 与三组 CSV 候选，零和数字顺序保留、无序组排序。无 job 显示“只更正未结算结果”；有 job 明示全额撤回旧 prize 后重新结算，需财务权限/显式模式。两步核对原因、旧结果/新候选、期次/政策版本和模式；超管不写。

更正历史、单据原版本/金额/旧核算/原派奖与冲正 ID 分页可查。reversing 和 resettling 分开；新 job 待批准/失败时跳转结算面板的当前代次处理，不重复整条更正。历史 job 明示曾入账，不显示为当前完成或可批准；跳转刷新相同 UUID 也重新加载代次。只读刷新同时重取选中详情，不停留在旧进度。

冻结普通 JSON 请求（兼容 Vue Proxy）、旧 draw ID、模式、账号/品牌/期次/键，SDK 不隐式刷新上下文后换目标。读到新状态不确认未知写；同键回执匹配后解除未知，再取实时详情；401 清除旧数据，后读断网不再重放已确认操作。仅页面会话内存，不承诺跨硬刷新恢复。显示不足中奖 available 时人工处理，不扣其他来源/自动解冻/生成欠款。

## 自动归档任务管理

后台“自动归档任务”独立懒加载，提供当前配置只读、任务分页与完整详情、中英文及PC/360px布局。配置版本、原任务版本、尝试数、保存时区和绝对区间分别显示；此页支持日/月独立启停，不提供历史回补控件。首次启用从品牌当天/月开始已确认，正式PUT及SDK见[29号合同](29-report-archive-activation.md)，配置编辑、原因核对和显式原键恢复已接入；平台查看及超管只读，原ACK与最新配置分开显示。授权品牌管理员针对failed填写原因、核对冻结账号/品牌/任务/版本/正文/键并勾选确认后才提交，超管只读。

未知请求在同会话内存保留，不因刷新列表、离页返回或语言切换自动重发；显式核对并勾选后原键重放。真实原pending ACK独立于最新completed详情，不拿GET确认未知写入。409成功重读原目标及列表后人工确认丢弃，当前401清会话，旧代次响应不影响新身份。UUID及任务按钮断行，无浮点分页总数或横向溢出；真实双端验证和接口边界见[28号合同](28-report-archive-task-management.md)。

## 人工奖励管理

后台“人工奖励”提供真实订单列表、当前详情和不可变动作历史，支持PC与360px布局及中英文切换。发放填写会员UUID、正整数积分和原因；撤销或继续使用当前详情版本，先核对冻结请求再勾选确认。不足待处理是已记录结果，不自动重试或解冻。原回执与当前查询独立展示；网络未知保留同会话原actor、品牌、目标、正文和键，禁止另建资金请求。409须成功刷新并人工确认丢弃，注销、401及账号变化清理内存，迟到响应不改绑或解锁其他意图。超级管理员只读，具体合同与测试环境见[人工奖励说明](20-manual-reward-orders.md)。

## 佣金更正管理

佣金周期分析是原报表页面的独立只读区域，显式查询、按周期结束时间选择整周期，显示覆盖、已知核算、完整/未知目标、实际净额及数学差；全部18项指标可见，移动端分组用可展开详情。修改筛选清除原结果和导出资格，权限、品牌/账号变化及迟到401隔离原响应；完整CSV校验摘要后下载，不触发任何金融写入。双语组件/SDK及1440/360px真实查询、窗口外入账、筛选清空和完整导出已开发验证，真机仍待验，见[38号](38-commission-cycle-analysis.md)。

后台“佣金更正”分别显示独立默认关闭开关、不可变计划及目标、原支付run、执行任务和实际目标。补发、追回、净额与实际已应用金额分别显示，积分字符串不经过浮点转换。人工/混合新计划单人批准，暂停只有显式continue，failed只有技术retry；准备retry不能批准资金。品牌暂停可处理已有财务工作，超级管理员只读。所有写入先冻结版本、原因、actor、品牌、目标、正文和键，再明确勾选确认。

断网或畸形响应保留原意图并锁定新写入，同会话离开再返回仍可人工核对后原键恢复；GET刷新不解除未知状态。匹配ACK独立保留，随后读取失败不重放已确认操作。409刷新全部相关状态后人工确认丢弃；注销、换账号/品牌及401清理，迟到401/409不污染新会话。内存恢复不承诺跨关闭/硬刷新。PC及360px移动布局、中英切换由真实浏览器验证；表格元数据重置全局nowrap，长UUID换行，宽度检查与配置viewport比较，不用已被溢出扩大的innerWidth掩盖问题。管理合同见[24号说明](24-commission-correction-management.md)。0060现有报表增加独立更正笔数/补发/追回，完整CSV为版本2；用户收件箱追加不可改写的佣金更正记录，固定说明正负含义及历史性质，见[25号合同](25-commission-correction-observability.md)。

## 用户首页钱包当前实现
