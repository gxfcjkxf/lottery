## 当时能力与配置归属

总后台在“彩种 → 自动开奖”发布共享来源、首期开奖时间、首期期号、固定秒周期及提前封盘秒数。期号从首期十进制数字连续递增，保留前导零；时间按锚点和固定秒周期推算。本期不支持每日重置期号、周历或任意上游格式转换，未明确的正式期号规则不作推断。

品牌后台在“规则配置 → 自动开奖”确认采用平台来源及周期，启用本品牌自动销售，并设置不早于平台要求的提前封盘。品牌不能改其他品牌或共享开奖源；需要调整共享来源和周期时由总后台发布新版本，再由品牌确认采用。

系统每秒维护当前及下一自动期次。已生成期次保存原周期和来源版本；品牌封盘时间也按期次固定。修改品牌秒数仅影响新预约期次；品牌禁售立即阻止新投注。封盘使用数据库时间，并有注单写入触发器再次校验。平台停用自动期次后停止新预约，已预约期次仍收集结果及结算，不自动转回旧人工期次。

用户投注页每秒更新倒计时、每5秒读取期次、结果、余额和注单。封盘归零后禁止选号及新确认，跨期预览失效；未知响应的原请求仍可按原幂等键重试。历史注单、钱包及开奖结果中心打开的期次详情也每5秒刷新。

## 历史固定开奖源协议

服务端环境变量`PLATFORM_DRAW_ALLOWED_ORIGINS`为显式允许的来源origin JSON数组，例如正式部署使用`["https://draw.vendor.com"]`。只接受HTTPS；开发／测试可显式允许`http://127.0.0.1:端口`。默认没有允许来源，不做网络兜底，也不自动抓取参考站。

配置地址不含查询参数、用户名或密码。采集器发出GET，附加`game_code`和`period_no`。如需Bearer密钥，界面仅填写以`DRAW_FEED_`开头的专用服务端环境变量名，值不写入数据库、页面或日志。请求3秒超时，不跟随重定向，响应上限64KiB。

响应示例：

```json
{
  "period_no": "202610160002",
  "drawn_at": "2026-10-16T02:11:58Z",
  "result": {"regular": [], "special": [], "digits": [5, 4, 5]}
}
```

六合彩使用`regular`六个普通号、`special`一个特别号、`digits`空数组。其余八个彩种使用三个有序0～9数字，允许数字重复。时间须不早于配置开奖时间，且不晚于服务器当前时间10秒以上；期号须精确一致，号码须符合平台模型。不同期次号码相同本身合法，不作为错误拒绝。

204／404表示无数据；错误期号、时间或号码记为异常；网络或状态错误记为来源失败；密钥缺失单独标记。结果不发布，保留待开奖及已冻结资金；5秒后重试同一来源。两后台显示最近检查状态与次数。合法结果经事务和期次锁发布一次，再由原六合彩／加拿大结算任务执行，不改变赔率快照或资金算法。

**正式API地址、响应样例及期号规则尚未提供。当前已完成本地可控源端到端验收，尚未连接正式开奖服务。** 若上游与上述协议不同，需要根据正式文档实现明确适配，不猜测字段或切换替代源。
