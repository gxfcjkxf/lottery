# 60. 总后台经营总览

总后台登录或恢复已有登录后默认进入「首页 / 经营总览」，品牌列表保留在品牌菜单。首页不使用已选品牌，不显示品牌选择器。退出登录、切换账号或会话失效后清除首页数据；重新登录回到首页。

## 页面与统计口径

- 首行：总会员、当前在线、昨日新增会员、今日投注人数。按各品牌汇总，同一账号在不同品牌分别计数；总会员含正常、停用账号，排除已删除账号。新增按首次加入各品牌的时间统计。在线和投注人数在品牌内计人数，跨品牌相加。
- 在线：近 5 分钟存在 `session_activity` 记录，且会员会话未撤销、未过期、全局账号正常、品牌会员正常或冻结并已接受条款、品牌未停用。注册和登录成功在同一事务记录活动；用户端既有 `/me` 心跳更新活动，写入间隔至少 30 秒。活动记录不参与资金授权，不修改 `AuthenticateTx` 的锁顺序或只读语义。
- 今天 / 昨天并列展示：成功投注积分、注单数、各品牌投注人数之和、已结算平台净赢、取消 / 退款积分。投注和注单按下单时间，输赢按结算完成时间，退款按实际退款时间归日。
- 平台净赢正数表示平台赢，负数表示平台输；退款中性，佣金、奖励和运营成本未扣除。合并普通规则、六合彩、加拿大和配置式四类注单。牛牛按实际损失减会员净赢计算，不使用最大风险冻结积分；风险冻结释放不计入取消 / 退款积分。
- 今日投注增幅比较昨日同时段；昨日比较前日完整自然日。比较基数为零时明确显示无可比数据。
- 当前未结投注包括历史未结和异常待处理注单。积分区另展示会员可用积分、待审核提现积分；冻结积分仍在接口返回，不在总览展示。提现笔数在待处理事项展示。
- 最近 7 日趋势支持投注积分、结算净赢、新增会员；今天为未完成日，支持正负输赢。
- 品牌贡献按今日投注积分排序取前 10 个品牌，显示真实品牌名称与今日结算净赢。待办汇总提现待审核、异常注单、结算失败任务、取消处理中 / 失败任务，不跨品牌执行操作。

所有日期边界统一按平台时区自然日计算。积分和计数以十进制字符串传输，前端以 BigInt 格式化和比较，不把累计积分转换为浮点数。单次 PostgreSQL 语句保证所有卡片使用同一数据快照。

## 接口与权限

`GET /api/v1/platform/overview` 只注册在总后台入口，要求当前平台管理账号具有 `overview.view.platform`。不接受 `X-Brand-ID` 或查询参数，不因超级管理员身份自动推导授权。品牌后台同名路径不存在，未经授权的账号不能读取跨品牌汇总。权限名称在共享中英文目录提供翻译，三端复用。

响应含 `snapshot_at`、`timezone`、`today`、会员 / 积分 / 待办计数、`yesterday_same_time_stake`、7 项 `days` 和最多 10 项 `brands`。字段及必填约束见生成的 OpenAPI。后台会话和数据响应沿用现有 no-store 及会话失效处理。

总后台和品牌后台的经营总览统一仅保留标题、指标名称、数值、图表与有数据的涨跌比较，移除描述性文案、快照时间、平台时区及「统计口径」。已有每分钟自动刷新，页首不显示手动刷新、自动刷新勾选框或业务快捷按钮。首次读取和失败重试使用共享全局加载；页面可见时每 60 秒后台刷新，不触发全局加载。失败清除本页汇总，显示本地化错误及重试，不显示零值成功结果。卸载时取消请求和轮询，拒绝迟到响应。首页文案集中在 `shared/src/overview-catalog.ts`，同步提供 en / zh-CN；两端共用 `ManagementOverview.vue`，各自维护独立 API 和权限。品牌首页见 [61 号](61-brand-overview.md)。
