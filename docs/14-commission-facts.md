# 佣金订单事实

2026-10-28，统一读取配置化订单。完整执行范围见[投注与结算统一说明](65-unified-configured-betting.md)。

`commission.Source.FinalOrderTx` 在调用方事务内锁定共享开奖结果，读取配置化订单的财务投影，校验原借记、派奖、退款、冻结亏损的真实记账及品牌／会员／账户归属。未结算返回 `not_final`；已结算但资金或归属证据缺失返回错误，不当作可计佣的零额。

计佣事实保留购买时冻结的归属与代理政策，不从今天的代理树重建。流水佣金以 `effective_points` 为基数；亏损佣金以实际消费减中奖积分的正数部分为基数。和局有效投注为零，牛牛的未消费预留不计作亏损。

不再提供旧结算任务、旧计算ID和旧结算世代字段。佣金核算周期自身的运行编号及审计历史仍然保留，实际派发继续校验完整核算事实、品牌派发开关、既有授权、已付金额与幂等流水。

实际数据库回归覆盖配置化订单的未结算、中奖、未中、退本、提现有效流水，以及带代理归属的亏损10分按30%只入账一次3分佣金。
