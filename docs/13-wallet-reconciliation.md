# 会员积分只读核对

2026-10-27 一期精简后，不再提供品牌批量对账任务、业务引用批量盘点、在线余额修复、任务重试或对应 worker。系统尚未投入使用，不保留旧接口、任务格式或修复流程。

保留会员钱包、不可变积分流水，以及 `GET /api/v1/admin/wallets/{memberID}/reconciliation` 的单会员只读核对；总后台沿用对应的查询接口。核对在账户共享锁内检查账本版本链、请求摘要、前后快照与余额重建结果，返回 consistent、expected、actual 和 issues，不修改积分或账本。

正常资金写入继续使用同事务业务记录、账户排他锁、幂等键、完整16分项、不可变流水及审计，拒绝损坏的当前余额和账本尾。不提供根据输入金额补平余额的接口。

原批量任务五张表、修复记录表、相应权限与后台入口已从当前基线和运行代码移除。现有开发库更新先备份，在副本核对新结构与剩余业务数据，再显式同步迁移记录。不得清库或单改 checksum。
