# 第一阶段实现任务拆分

## 任务规则

- 每个任务必须有数据库迁移、权限校验、审计、测试和接口文档。
- 资金/投注任务必须包含并发和幂等测试。
- UI 任务必须覆盖桌面和 360px 移动视口。
- 未决事项通过 `08-acceptance-and-open-items.md` 的编号关闭后，才能进入对应生产实现。

## EPIC-01 工程与运行环境

依赖：无。

- 创建 backend、user-web、admin-web、shared 包目录。
- 配置 lint、format、test、migration、seed、build、Docker Compose。
- 接入 PostgreSQL、Redis、消息队列、对象存储适配器和配置加载。
- 实现 request_id、结构化日志、健康检查和基础错误响应。

完成标准：新开发者按 README 可启动完整本地环境，数据库迁移可重复执行。

## EPIC-02 身份、品牌和权限

依赖：EPIC-01。

- 全局注册、密码登录、Telegram 验证接入（未配置外部应用时关闭；本地测试签名不能代替真实授权验收）。
- 品牌域名解析、成员加入、加入来源快照。
- 后台账号、角色、权限、品牌范围和会话踢出。
- 用户状态、首次补充用户名/手机号和协议版本。

完成标准：跨品牌越权测试全部通过；用户和后台端到端登录可用。

## EPIC-03 积分账本和人工充值

依赖：EPIC-02。

- 账户余额、来源余额、冻结余额和提现余额。
- 追加账本、前后快照、来源分配、冲正和幂等。
- 充值单创建/确认，第一期单人后台流程。
- 冻结、解冻和人工调整。
- 账户行锁、版本号、对账查询。

完成标准：并发扣款不超扣；任意余额可由账本还原；所有调整有审计。

## EPIC-04 彩种、玩法和规则引擎

依赖：EPIC-01、EPIC-02。

- 三类号码模型和号码池校验。
- 规则组件 AST、组合展开、属性和特征计算。
- 奖级、赔率、封顶、四舍五入、复式和倍投。
- 草稿、模拟、审核、立即/下期生效和回滚。

完成标准：规则样例可通过后台创建、模拟和审核；历史版本不可被覆盖。

## EPIC-05 期次和开奖

依赖：EPIC-04。

- 每日/固定间隔期次生成和唯一约束。
- 期次状态流转、品牌暂停、截止锁盘。
- API/DOM 结果源适配器接口和伪实现。
- 主备切换、结果校验、人工开奖、锁定和纠正。

完成标准：所有状态变化可审计；来源失败能按优先级切换；人工开奖后不再取其他来源。

## EPIC-06 选号、注单和取消

依赖：EPIC-03、EPIC-04、EPIC-05。

当前：S5-a1/a2/a3 已完成真实预览、下注、用户取消和品牌运营异常标记/取消，以及双端对应页面。S5-a4 接入整期取消和持久化分批原来源退款；单独注单判定取消入口仍待实现，本 EPIC 尚未整体完成。

- 预览、选号规范化、复式、倍投和限额。
- 注单事务、来源扣款、幂等、重复投注检查。
- 用户取消、运营取消异常注单、判定取消和全额原路退款。

完成标准：重复请求不重复扣款；取消可还原原来源；截止并发场景无越界注单。

## EPIC-07 结算和回溯

依赖：EPIC-03、EPIC-04、EPIC-05、EPIC-06。

当前：人工异常证据与终态管理已接入。普通结算、派奖、失败重试、结果纠正回溯尚未实现；自动派奖或运营确认的业务选择仍待明确。

- 按规则版本判断中奖和奖级。
- 派奖写中奖积分和账本。
- 异常注单标记、人工处理和不可自动重试。
- 结算失败人工重试。
- 结果纠正时冲正原数据并重新结算。

完成标准：同一结算事件幂等；原结算和反向流水可完整追溯；期次正确关闭。

## EPIC-08 提现和流水周期

依赖：EPIC-03、EPIC-06。

- 提现资格、N 倍流水、彩种优先级。
- 提交锁定来源积分、审核、内部处理、成功/失败/驳回/取消。
- 进行中唯一约束、幂等和原路退回。

完成标准：并发提交只能产生一个申请；流水周期按提交时间切换；失败不清空历史流水。

## EPIC-09 代理、佣金和奖励

依赖：EPIC-06、EPIC-07、EPIC-08。

- 代理树、加入归属快照和下级发展权限。
- 输赢/流水模式、比例上限和配置版本。
- 周结/月结、幂等发放、最低 0 和人工调整。

完成标准：上级比例校验在后端生效；周期任务重复执行不重复发放；原计算记录不可覆盖。

## EPIC-10 PWA 和管理 UI

依赖：EPIC-02 至 EPIC-09 的接口可用。

- 按 `05-ui-spec.md` 实现用户端和管理端路由。
- 完成品牌主题、多语言、状态和错误处理。
- 完成移动端审核、监控、查询和应急操作。
- 按交互原型验收关键流程。

完成标准：用户端下注和提现端到端可用；管理端可完成开奖、审核、异常处理和账本查询。

## EPIC-11 报表、通知和运营

依赖：EPIC-07、EPIC-08、EPIC-09。

- 注单、中奖、提现、积分、佣金、奖励和对账报表。
- 站内通知、模板、多语言、重试和查询。
- 日结/周结/月结任务和异常告警。

完成标准：报表与账本抽样对账一致；失败通知和失败任务可重试并可审计。

## EPIC-12 压测、安全和交付

依赖：全部 P0/P1 任务。

- 500 在线用户、500 次/秒投注压力测试。
- 并发、幂等、品牌隔离、权限、注入、XSS、CSRF 和会话安全测试。
- 备份恢复、主库故障切换、队列堆积和外部源失败演练。
- 生成部署、监控、恢复和人工运营手册。

完成标准：`08-acceptance-and-open-items.md` 的 P0 验收全部通过，未决阻塞项关闭。
