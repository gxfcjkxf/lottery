# 平台彩种删除、下架与品牌停用

2026-10-16，适用于九个共享平台彩种。总后台彩种列表新增状态和操作列；品牌后台规则配置中的平台彩种列表新增本品牌启用／停用。中英文共用既有目录，360px显示紧凑卡片，让操作按钮无需横向滚动即可看到；820px及桌面保留表格。

## 行为

- 总后台“删除彩种”：仅无期次、无注单时允许。采用不可恢复的目录删除标记，列表和详情不再返回该彩种；既有不可变配置、连接和审计证据不清除，代码仍被占用。已有期次时按钮禁用，绕过界面请求也会被服务端拒绝。
- 总后台“下架”：所有品牌停止新投注，用户列表隐藏，自动调度不再预约新期次。既有预约期次仍采集结果，已有注单继续结算，历史记录与钱包流水保留。已下架筛选可查看、配置及重新上架。
- 品牌“本品牌停用”：只修改当前品牌连接状态，用户列表隐藏、禁止新投注，不改变其他品牌或平台开奖。重新启用不自动修改销售赔率或封盘设置。
- 旧投注页可继续查看历史，显示销售已暂停；服务端预览和购买均校验状态。状态校验持有平台彩种和品牌连接锁，与下架／停用串行；数据库插入保护也校验可售状态。已有订单的结算不经过新投注门禁。

相关结构已包含在 `0001_baseline.up.sql`，按[空库安装](../README.md#空库安装)操作。提供两个带幂等的接口：

```text
POST /api/v1/platform/platform-games/{id}/lifecycle
{ expected_version, status: active|offline|deleted, reason }

POST /api/v1/admin/platform-games/{id}/availability
{ expected_version: brand_version, enabled, reason }
```

平台需要 `platform_game.write.platform`，品牌需要当前品牌 `platform_game.sell.brand`。两入口不互相暴露写接口；操作原因、当前授权及版本均校验，变动写入审计。

## 验收

Computer Use逐个停用、重新启用九彩种，用户投注入口均隐藏；直接打开旧页面时选号禁用、历史保留。之后逐个下架九彩种，并在下架状态等待原有自动开奖及派彩。第80期9张合成积分注单全部结算，包含六合彩42组合、牛牛620冻结／210损失／410释放；余额54894→65833，冻结归零，逐单历史、HTTP钱包流水和数据库业务对账一致。

恢复九彩种上架后继续可试用。唯一删除的对象为本次新建的空白验收彩种 `lifecycle_disposable_20261016`。浏览器检查删除确认提示及删除后消失；删除请求和重复提交由本地受环境限制的HTTP验收程序执行，没有清理既有彩种或资金数据。

浏览器检查两后台中英文、360px及820px弹窗与列表，未出现页面横向溢出。验收修复了手机表格操作列藏在右侧、品牌按钮未继承通用样式的问题。

自动化检查：生命周期服务、六合彩／加拿大资金、自动开奖及HTTP专项；全量合同105项、shared88、用户160、总后台120项；静态178项、三端类型检查与构建、OpenAPI生成与校验。资金测试覆盖停用后拒绝扣款、已有注单派彩、重复结算、旧版本拒绝及品牌权限隔离。
