# 61. 品牌后台首页仪表盘

> 2026-10-28 执行范围更新：投注、结算、佣金／提现事实与经营统计均以[统一配置化链路](65-unified-configured-betting.md)及当前 OpenAPI 为准。文中的旧品牌期次、专用订单、结算任务、旧夹具与旧容量结果是历史设计或证据，不代表当前可用接口。

品牌后台登录、恢复登录及退出后重新登录，默认进入「首页 / 品牌经营总览」。侧栏、品牌标识和移动端首页入口均指向首页。首页直接显示在导航中，不设「概览」分组；移除与首页重叠的「运营工作台」页面和入口，侧栏品牌标识只展示品牌名称与 Logo。具体任务从对应业务菜单进入。

## 展示与口径

品牌后台和总后台复用 `shared/src/ManagementOverview.vue`，使用共同布局、令牌、全局加载、精确积分格式化及趋势计算。各端保留独立接口、身份校验和错误处理，不跨端导入应用组件。共用文案位于 `shared/src/overview-catalog.ts`，品牌覆盖文案同步提供 en / zh-CN。

首页只展示当前品牌：

- 会员总数、近 5 分钟在线会员、昨日新增会员、今日投注人数。总会员按当前品牌成员统计，排除已删除的平台账号；新增按首次加入该品牌的 `joined_at`，不按全局注册时间。用户在其他品牌有活动，不计入当前品牌在线数。
- 今天 / 昨天投注积分、注单数、投注人数、已结算净赢与退款积分。输赢以品牌视角，正数表示品牌赢。四类注单和牛牛风险资金口径沿用 [60 号](60-platform-overview.md)，退款与风险释放分开。
- 当前未结投注、会员可用积分、待审核提现；冻结积分仍在接口返回，不在总览展示。全部在服务端按品牌过滤。
- 最近 7 日投注积分、结算净赢、新增会员趋势，以及当前品牌提现、异常注单、结算失败和取消待办。不展示跨品牌排行。

会员总数、新增会员及会员可用 / 冻结积分均排除已注销品牌会员和已删除全局用户；历史账本与投注记录继续保留。

日期统一使用平台时区。今日和昨日均不展示涨跌比较百分比。待处理事项位于页面顶部、会员统计之前，突出待审核提现数量；点击“提现待审核”进入提现管理，默认筛选待审核申请，沿用当前品牌和既有提现权限。所有积分及计数以十进制字符串传输，积分支持最多两位小数，计数仍为非负整数，不使用浮点数累加。

## 接口与权限

`GET /api/v1/admin/overview` 要求 `overview.view.brand`、有效 `X-Brand-ID` 和当前账号的对应品牌范围。固定通用管理入口可选择账号已授权的品牌；显式绑定品牌的管理入口仍要求品牌头与域名品牌一致。总后台账号、用户端会话、无权限账号均不得读取。品牌后台 `/brands` 返回账号明确分配的基础品牌目录，不额外要求 `brand.view.brand`，不因此授予会员、资金、首页或配置权限。

SQL 在合并四类注单前，分别按已授权品牌过滤。会员、会话、积分钱包、提现、结算和取消任务的查询各自带品牌条件。响应返回 `brand_id`，客户端严格核对，不接受其他品牌或全平台响应。读取事务内复核会话和权限，保持已有品牌授权锁。

两端总览统一保留标题、指标名称、数值和图表，总后台另保留有数据的涨跌比较，移除描述性文案、快照、时区及统计口径；已有自动刷新，不显示刷新控件或工作台快捷按钮。首次进入和失败重试接入共享全局加载；页面可见时每 60 秒后台刷新，不触发全局加载。失败显示本地化错误及重试，清除旧汇总，不补零。账号、品牌或首页权限改变后重建组件，卸载时取消请求和定时器，拒绝迟到响应。
