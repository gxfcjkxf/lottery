# 61. 品牌后台首页仪表盘

品牌后台登录、恢复登录及退出后重新登录，默认进入「首页 / 品牌经营总览」。侧栏、品牌标识和移动端首页入口均指向首页。首页直接显示在导航中，不设「概览」分组；移除与首页重叠的「运营工作台」页面和入口，侧栏品牌标识只展示品牌名称与 Logo。具体任务从对应业务菜单进入。

## 展示与口径

品牌后台和总后台复用 `shared/src/ManagementOverview.vue`，使用共同布局、令牌、全局加载、精确整数格式化及趋势计算。各端保留独立接口、身份校验和错误处理，不跨端导入应用组件。共用文案位于 `shared/src/overview-catalog.ts`，品牌覆盖文案同步提供 en / zh-CN。

首页只展示当前品牌：

- 会员总数、近 5 分钟在线会员、昨日新增会员、今日投注人数。总会员按当前品牌成员统计，排除已删除的平台账号；新增按首次加入该品牌的 `joined_at`，不按全局注册时间。用户在其他品牌有活动，不计入当前品牌在线数。
- 今天 / 昨天投注积分、注单数、投注人数、已结算净赢与退款积分。输赢以品牌视角，正数表示品牌赢。四类注单和牛牛风险资金口径沿用 [60 号](60-platform-overview.md)，退款与风险释放分开。
- 当前未结投注、会员可用积分、待审核提现；冻结积分仍在接口返回，不在总览展示。全部在服务端按品牌过滤。
- 最近 7 日投注积分、结算净赢、新增会员趋势，以及当前品牌提现、异常注单、结算失败和取消待办。不展示跨品牌排行。

日期统一使用平台时区。今日增幅比较昨日同时段，昨日比较前日完整自然日；基数为零时明确无可比数据。所有积分及计数以十进制字符串传输，不使用浮点数累加。

## 接口与权限

`GET /api/v1/admin/overview` 要求 `overview.view.brand`、有效 `X-Brand-ID`，并要求品牌头与管理入口域名对应的品牌一致。即使员工拥有多个品牌权限，也不能从当前品牌入口读取其他品牌首页。总后台账号、用户端会话、无权限账号均不得读取。

SQL 在合并四类注单前，分别按已授权品牌过滤。会员、会话、积分钱包、提现、结算和取消任务的查询各自带品牌条件。响应返回 `brand_id`，客户端严格核对，不接受其他品牌或全平台响应。读取事务内复核会话和权限，保持已有品牌授权锁。

两端总览统一保留标题、指标名称、数值、图表与有数据的涨跌比较，移除描述性文案、快照、时区及统计口径；已有自动刷新，不显示刷新控件或工作台快捷按钮。首次进入和失败重试接入共享全局加载；页面可见时每 60 秒后台刷新，不触发全局加载。失败显示本地化错误及重试，清除旧汇总，不补零。账号、品牌或首页权限改变后重建组件，卸载时取消请求和定时器，拒绝迟到响应。

## 发布前权限变更

`0001_baseline.up.sql` 注册 `overview.view.brand` 并赋予品牌内置角色；`create-admin --brand` 初始化同样包含该权限。自定义角色需显式授权，不从原有财务或会员权限自动推导首页权限。

实现阶段先在独立新建测试库通过正常基线安装验证，没有重启共享服务或登录共享 `admin` 账号。2026-10-20 经用户明确要求，已完成共享开发环境更新：停止 API / worker 后完整备份，在恢复副本验证权限增量、与新基线的结构一致及原有业务数据指纹，再同步共享库权限和迁移记录，启动更新后的 API / worker。没有清库，也没有仅修改 checksum 绕过验证。

共享地址为品牌后台 `http://localhost:5184`、总后台 `http://localhost:5185`，共用 API `127.0.0.1:8085`。品牌内置角色已增加 `overview.view.brand`，总后台原有 `overview.view.platform` 保留。保留原认证密钥和现有会话，刷新页面后读取最新权限。

本次上线验证仅使用专用 `home_probe_brand_1020` / `home_probe_platform_1020` 账号，复用现有内置角色确认真实授权；验证后停用两个验证账号并撤销其会话，没有登录共享 `admin`。两个首页均验证默认进入、真实汇总与页面一致、手动刷新和恢复会话，品牌页额外验证跨品牌请求被拒绝。备份、副本结构对比、业务数据指纹、权限差异、更新二进制摘要、运行 PID、浏览器截图及验证结果保存于 `.local/shared-home-rollout-20261020/`，凭据文件权限为 0600。
