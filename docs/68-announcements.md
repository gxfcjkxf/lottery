# 平台与品牌运营公告

一期实现独立运营公告，不改变充值、派奖等业务通知或历史收件箱。代码位于 `backend/internal/announcement`，三端共用 `shared/src/AnnouncementsManagement.vue`、公告目录及内容渲染器。

## 入口与权限

- 平台：运营 → 公告；无需先选品牌，可面向全部或指定品牌。
- 品牌：品牌设置 → 公告；仅管理本品牌。
- 用户：侧栏／菜单公告、账户服务公告、登录／注册卡片公告链接；`/announcements` 对游客开放。其他业务页保留原登录要求。
- 精确权限分别为 `announcement.view.brand|platform`、`announcement.write.brand|platform`、`announcement.publish.brand|platform`。新建初始化管理员角色包含对应权限；已有角色须在角色管理显式授权，不按超级管理员身份隐含放行。
- 查看、编辑及发布分别授权。修改已发布内容、下架和对应幂等回放需要发布权限。品牌不能编辑、屏蔽或引用平台公告素材；跨品牌角色不能操作其他品牌公告。

## 内容与发布

中英文标题、正文、图片及按钮链接分别编辑。内置 HTML 工具栏提供加粗、斜体、标题、列表、强调、链接及图片插入，预览使用用户端同一渲染器。支持纯文字、纯图片与图文混排。

HTML 仅允许 `p br h2 h3 strong em u s ul ol li blockquote a img mark`。只允许链接 `href`、图片 `src/alt` 及系统规范化的 `rel`；脚本、iframe、SVG、事件属性、任意样式和外部图片均明确拒绝。链接允许站内相对路径和无凭据 HTTPS 地址。图片须实际上传，限制 PNG/JPG/WebP、5 MiB、单边4096px；服务端完整解码并校验归属。上传本身不发布公告。

草稿可以不完整；发布要求完整双语内容。没有自动翻译或缺失语言回退。保存并发布才使编辑生效。状态为草稿、待生效、展示中、已结束、已下架；开始时间可留空表示立即，结束时间可留空表示长期。排期输入统一按平台设置的时区转换成 UTC，服务端按当前时间过滤，不依赖 worker 定时刷新。

排序固定为：平台置顶 → 平台普通 → 品牌置顶 → 品牌普通；组内排序值升序、发布时间降序、ID。置顶不突破排期、受众及控频。

## 自动展示与免打扰

展示对象支持全部用户、游客、登录会员，默认全部。自动弹窗在首页、登录／注册页进入后触发，其他操作途中不插入；有其他模态框时等待关闭。公告列表始终允许主动打开当前有效公告，不受自动展示频率限制。

频率为每会话一次、每天一次、每隔1～365天一次、仅一次。会员会话取真实登录会话；游客会话取浏览器标签页会话。游客身份由品牌专属 HttpOnly Cookie 标识，记录保存在服务端。会员记录按品牌及会员隔离、跨设备共享；登录时合并当前浏览器记录，当前会话已展示的公告不会因登录重复弹出。

只在某条公告实际打开后记录该条展示；没翻到的公告不算看过。普通修改不清除历史控频；勾选“重新提醒”发布会生成新展示代次。

“今日不再显示本组公告”抑制本次自动展示组的全部公告，按平台时区的自然日截止。组内所有公告均允许今日免打扰时才提供该复选框。当天后续新发布的公告及明确重新提醒的新代次仍可展示。游客记录受浏览器 Cookie 保留范围限制；没有跨浏览器游客身份追踪。

一期不做强制阅读、倒计时、自动轮播、审批流、高级会员分群、重复日历排期、营销统计或导出。

- `backend/internal/announcement/model_test.go`：HTML安全、规范化、时区日界及状态。
- `backend/internal/httpapi/announcements_test.go`：独立数据库下真实HTTP／事务，覆盖权限及回放、品牌隔离、平台优先、指定品牌、四种频率、排期、整组免打扰、新公告、图片、游客Cookie及真实会员登录合并。
- `playwright.announcements.config.ts`：真实三端页面与隔离的合成接口，覆盖双语、安卓／iOS横竖屏、桌面、320px及内容断点、编辑预览、平台品牌选择、未知结果原键重试与无横向溢出。
